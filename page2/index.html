Clock Tunnel



This website is based on the theme “Time as non-linear and branching.” Using the clock as a motif, it explores time not as a fixed linear progression, but as a circular and branching structure where moments diverge, repeat, and return in unexpected ways.

Each ring visible on the homepage functions as a clickable passage. When a user selects a ring, they are drawn into a new section, as if being pulled into another layer of time. Each section presents a distinct visual effect and interactive structure, allowing the viewer to experience another branch of time.
